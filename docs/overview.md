# Overview

modernstudio is a minimalist music app, made only for its author. Very similar to Caustic. Windows only. No reverb or any other effect.

## Instruments

1. Drums
2. Bass
3. Rhythm Guitar
4. Lead Guitar
5. Keys (for vocals)

Each instrument can be muted or isolated, and has its own volume.

## Modes

- **Pattern mode:** build patterns for one instrument. The pattern loops while it plays.
- **Song mode:** arrange patterns on a timeline.

There is also a master mixer screen. Each instrument also has its own page for editing its notes and its envelope.

## Why it exists

Caustic cannot do the one special feature: the guitar and bass editors are not a horizontal piano roll but an upside-down arrangement of strings. See [instrument-layouts.md](instrument-layouts.md).

## Scope

The whole project described in these docs is the day-one scope. Design and look are deferred. The tech stack has no stated preference.
