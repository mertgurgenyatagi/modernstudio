# Instrument layouts

All instruments can play several notes at once (chords). There are no chord shortcuts: notes are placed one at a time.

## Guitars and bass: the string layout

Take a piano roll and turn it upside down, so the lowest pitch is at the top. Then group the rows by string. Each string is a block of rows, starting at its open string (highlighted) and running up the frets.

Example, top to bottom, for the first two guitar strings:

```
E2 (highlighted)
F2
F#2
G2
G#2
A2
Bb2
B2
A2 (highlighted)
Bb2
B2
...
```

- Each string shows the open string plus 7 frets by default. The fret count can be set to 5 or 12 instead. It applies to the whole instrument, not to individual strings.
- The same pitch can sit on two strings, and these are separate positions.
- Two notes can sound on the same string at the same time.
- A placed note shows its fret number. This was left to the assistant.
- Tuning cannot be changed.
- Rhythm Guitar and Lead Guitar are identical in layout. They use standard six-string tuning: E2, A2, D3, G3, B3, E4.
- Bass uses standard four-string tuning, starting at E1: E1, A1, D2, G2.

## Drums

Not a piano roll. Rows from bottom to top: kick, snare, hi-hat, open hi-hat, crash.

Drum hits can use all six note values. They have no length: each hit plays for the full duration of its sound.

## Keys

For vocals. A regular piano roll. The agreed range is C2 to C6.
