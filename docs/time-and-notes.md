# Time and notes

## Tempo and meter

- BPM is a whole number from 40 to 300. This range was an example the user accepted.
- Meter is 4/4 or 3/4.
- BPM and meter are set for the whole project, on the mixer page. They can be changed at any point while working, but they always apply to the entire song. They cannot be segmented or changed partway through playback.
- A new empty project is 120 BPM in 4/4.
- A metronome click can be turned on while playing. It is not part of the WAV export. There is no count-in.

## Note values

Whole, half, quarter, 16th, third and half of a third. A third is one third of a quarter note (a triplet). Everything is quantized. There is no unquantized placement.

One pattern can mix straight notes and third notes.

## Placing notes

Select the note value first, then place. A placed note can be dragged longer or shorter.

A note can ring past the end of its pattern into the next one when the instrument's release is long enough.

## When the meter changes

Notes keep their positions. Switching 4/4 to 3/4 shortens the bar, and notes that now fall outside the bar are kept but not played, and return if the meter is switched back. This follows the same rule as shortening a pattern.
