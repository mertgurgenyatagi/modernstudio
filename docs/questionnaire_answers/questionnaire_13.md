Questionnaire 13

1. Does the editor scroll sideways when a pattern is wider than the window?
The pattern editor always has a fixed length of one bar. You scroll to see more. But there is a button to see the entire pattern. It's a basic toggle.

2. Can two notes sound on the same string at the same time?
Allow it.

3. Does the metronome play a count-in before playback starts?
No.

4. Does WAV export respect mute and isolate?
No.

5. Can the window be resized and maximized?
Yes.
